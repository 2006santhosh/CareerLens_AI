# API Overview

Base URL: `/api`. All endpoints except `/auth/register`, `/auth/login`, and `/health` require
`Authorization: Bearer <token>`. Interactive docs are auto-generated by FastAPI at `/docs` when the
backend is running.

## Auth
| Method | Path | Description |
|---|---|---|
| POST | `/auth/register` | Create an account, returns a JWT |
| POST | `/auth/login` | Returns a JWT |
| GET | `/auth/me` | Current user |

## Profile / onboarding
| Method | Path | Description |
|---|---|---|
| POST | `/onboarding` | Complete multi-step onboarding (target career, skills, hours, interests) |
| GET | `/profile` | Current profile |
| PUT | `/profile` | Update target career, weekly hours, learning style, GitHub username |

## Skills
| Method | Path | Description |
|---|---|---|
| GET | `/skills` | List canonical skills (optional `?category=`) |
| GET | `/skills/categories` | List distinct categories |
| GET | `/skills/profile` | Current user's per-skill level/status/evidence |
| GET | `/skills/{id}` | Skill detail |
| GET | `/skills/{id}/dependencies` | Prerequisites and unlocked skills |

## Careers
| Method | Path | Description |
|---|---|---|
| GET | `/careers` | List careers |
| GET | `/careers/{id}` | Career detail: required skills, importance, target level, match % |

## Evidence
| Method | Path | Description |
|---|---|---|
| POST | `/resumes/upload` | Upload PDF/DOCX, runs AI extraction (live or demo), stores evidence |
| GET | `/evidence` | List current user's evidence |
| POST | `/evidence` | Add manual evidence (project/certification/github/self_reported) |
| DELETE | `/evidence/{id}` | Remove evidence |
| POST | `/github/analyze?username=` | Best-effort public-repo analysis (optional feature) |
| POST | `/job-description/analyze` | Paste a JD, get match % + missing skills |

## Gap analysis
| Method | Path | Description |
|---|---|---|
| POST | `/gap-analysis` | Run gap analysis against the current target career |
| GET | `/gap-analysis/{career_id}` | Run gap analysis against a specific career |

## Roadmap
| Method | Path | Description |
|---|---|---|
| POST | `/roadmaps/generate` | Generate/regenerate the active roadmap for the target career |
| GET | `/roadmaps/current` | Fetch the active roadmap |
| PATCH | `/roadmaps/items/{id}` | Update an item's status (pending/in_progress/completed) |

## Assessments
| Method | Path | Description |
|---|---|---|
| GET | `/assessments` | List assessments with the user's best score/attempt count |
| GET | `/assessments/{id}` | Assessment questions (no correct answers leaked) |
| POST | `/assessments/{id}/submit` | Score, update skill level + verification, may regenerate roadmap |

## Dashboard / readiness / analytics
| Method | Path | Description |
|---|---|---|
| GET | `/dashboard` | Aggregated dashboard payload |
| GET | `/readiness` | Readiness breakdown for the target career, with explanations |
| GET | `/analytics/progress` | Readiness trend, category distribution, verified vs unverified, scores |
| GET | `/placement/analytics` | Aggregate, anonymized cross-student gap analytics |

## Errors

All errors return `{"detail": "<human-readable message>"}` with an appropriate HTTP status code
(400 for validation issues like a missing target career, 401 for auth failures, 404 for missing
resources, 422 for unparseable uploads, 502 for unavailable third-party services like GitHub).
